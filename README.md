# Garage AI Art — Culture Conference 2026

A static event website for the **Garage AI Art Culture Conference**, a three-day celebration of the intersection of artificial intelligence and human creativity held at The Garage in San Francisco's SoMa District.

## Event Highlights

- 🎨 **20+ interactive AI art exhibits** — generative installations, emotion-reactive paintings, cultural heritage remixes, and more
- 🎤 **40+ artists & speakers** — technologists, ethicists, linguists, and generative artists
- 🗓 **May 16–18, 2026** — in-person at The Garage, SoMa District + hybrid livestream
- 🎟 **Free & open to the public**

## Project Structure

```
.
├── index.html   # Main event landing page
├── styles.css   # Page styles (dark theme, responsive)
└── README.md
```

## Running Locally

Open `index.html` directly in any modern browser — no build step required.

```bash
open index.html
# or
python3 -m http.server 8080   # then visit http://localhost:8080
```

## Sections

| Section | Description |
|---------|-------------|
| **Hero** | Event date, location, quick-access CTA |
| **Stats** | At-a-glance numbers |
| **Exhibits** | Cards for all AI art installations |
| **Schedule** | Day-by-day program across all 3 days |
| **Speakers** | Featured artists and presenters |
| **Register** | Email sign-up form (client-side) |
